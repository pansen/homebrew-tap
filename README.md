# Pansen Tap

## How do I install these formulae?

`brew install pansen/tap/<formula>`

Or `brew tap pansen/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "pansen/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
